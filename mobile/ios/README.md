# NetworkZeroMonitor - iOS Build Configuration

This directory contains iOS-specific configuration and build files for the NetworkZeroMonitor mobile application.

## Structure

```
ios/
├── NetworkZeroMonitor/       # Main app files
├── NetworkZeroMonitor.xcodeproj/  # Xcode project (generated)
├── Podfile                   # CocoaPods dependencies (generated)
└── README.md                 # This file
```

## Building

To build the iOS app, follow the instructions in the [mobile README](../README.md) or the [DEPLOYMENT guide](../../DEPLOYMENT.md).

### Requirements

- macOS
- Xcode 12 or higher
- CocoaPods

### Setup

```bash
cd ios
pod install
```
