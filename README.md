# 🇿🇦 Leer Afrikaans - Word Learning Webapp

A comprehensive, interactive Afrikaans word learning web application with offline capabilities. Master Afrikaans vocabulary through engaging flashcards, quizzes, and matching games!

## ✨ Features

### 📚 Multiple Learning Modes

1. **Flashcards Mode**
   - Interactive flip cards showing Afrikaans words and English translations
   - Example sentences for context
   - Text-to-speech pronunciation support
   - Mark words as known to track progress
   - Navigate through cards easily

2. **Quiz Mode**
   - 10-question quizzes with multiple-choice answers
   - Bidirectional translation (Afrikaans ↔ English)
   - Instant feedback on answers
   - Score tracking and accuracy statistics
   - Randomized questions for varied practice

3. **Matching Game**
   - Match Afrikaans words with English translations
   - Timed challenges to improve speed
   - Visual feedback for correct/incorrect matches
   - Best time tracking

4. **Statistics Dashboard**
   - Track total words learned
   - Quiz accuracy percentage
   - Number of quizzes completed
   - Best matching game time
   - List of all known words

### 🎯 Difficulty Levels

- **Beginner**: 100 essential Afrikaans words
- **Intermediate**: 200 common words and phrases
- **Advanced**: 300+ comprehensive vocabulary

### 📱 Progressive Web App (PWA)

- **Offline-First**: Works without internet connection
- **Installable**: Add to home screen on mobile devices
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile
- **Local Storage**: All progress saved locally in your browser

### 🎨 Vocabulary Categories

The app includes words across various categories:
- Basic nouns (animals, family, body parts)
- Numbers and colors
- Adjectives and descriptive words
- Common verbs and phrases
- Advanced topics (science, sports, emotions)
- Everyday conversation words

## 🚀 Getting Started

### Option 1: Open Directly in Browser

1. Clone this repository:
   ```bash
   git clone https://github.com/AntwerpDesignsIonity/Offline-Ai-Mobile-Antwerp-Designs-Ecosystems-Ionity-AEDI.git
   cd Offline-Ai-Mobile-Antwerp-Designs-Ecosystems-Ionity-AEDI
   ```

2. Open `index.html` in your web browser (double-click the file or use File → Open)

### Option 2: Use a Local Server

1. Install dependencies (optional, for development server):
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm start
   ```

3. Open your browser and navigate to:
   ```
   http://localhost:8080
   ```

### Option 3: Deploy to a Web Server

Upload all files to any static web hosting service (GitHub Pages, Netlify, Vercel, etc.)

## 📖 How to Use

### Flashcards
1. Click on a card to flip it and see the translation
2. Use navigation buttons to move between cards
3. Click "I Know This" to mark words you've mastered
4. Click the 🔊 icon to hear pronunciation

### Quiz
1. Select the difficulty level
2. Choose the correct translation from 4 options
3. Get instant feedback on your answers
4. View your final score and accuracy

### Matching Game
1. Click pairs of cards to match Afrikaans and English words
2. Try to complete all matches as quickly as possible
3. Beat your best time!

### Statistics
- View your learning progress
- See which words you've mastered
- Track your quiz performance
- Reset progress if you want to start fresh

5. **Review Known Words**: Periodically review words you've marked as known
6. **Set Goals**: Try to learn 5-10 new words per day
