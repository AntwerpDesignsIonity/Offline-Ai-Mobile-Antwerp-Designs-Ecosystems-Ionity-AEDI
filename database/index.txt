DATABASE INDEX

----------

DATA MODELS:
------------
User Domain:
```sql
CREATE TABLE users (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  email VARCHAR(255) UNIQUE NOT NULL,
  password_hash VARCHAR(255) NOT NULL,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW(),
  is_active BOOLEAN DEFAULT TRUE
);

CREATE TABLE profiles (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id),
  first_name VARCHAR(100),
  last_name VARCHAR(100),
  avatar_url TEXT,
  bio TEXT,
  preferences JSONB
);
```

AI Domain:
```sql
CREATE TABLE ai_models (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name VARCHAR(255) NOT NULL,
  version VARCHAR(50),
  model_type VARCHAR(100),
  model_path TEXT,
  accuracy DECIMAL(5,4),
  created_at TIMESTAMP DEFAULT NOW(),
  is_active BOOLEAN DEFAULT TRUE
);

CREATE TABLE predictions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  model_id UUID REFERENCES ai_models(id),
  input_data JSONB,
  output_data JSONB,
  confidence DECIMAL(5,4),
  processing_time_ms INTEGER,
  created_at TIMESTAMP DEFAULT NOW()
);
```

GETTING STARTED:
----------------
PostgreSQL Setup:
1. Install PostgreSQL 15+
2. Create database: createdb aedi_platform
3. Run migrations: npm run migrate
4. Seed data: npm run seed

MongoDB Setup:
1. Install MongoDB 6.0+
2. Create database: use aedi_platform
3. Import collections: npm run mongo:setup

Redis Setup:
1. Install Redis 7.0+
2. Configure: /config/redis.conf
3. Start server: redis-server

CONNECTION STRINGS:
-------------------
PostgreSQL:
postgresql://user:password@localhost:5432/aedi_platform

MongoDB:
mongodb://localhost:27017/aedi_platform

Redis:
redis://localhost:6379
