INFRASTRUCTURE & DEVOPS INDEX
==============================

This directory contains infrastructure, DevOps, and deployment configurations for the AEDI platform.

STRUCTURE:
----------
/docker/            - Docker configurations
  /images/          - Custom Docker images
  /compose/         - Docker Compose files
  
/kubernetes/        - Kubernetes manifests
  /deployments/     - Deployment configs
  /services/        - Service definitions
  /ingress/         - Ingress rules
  /configmaps/      - Configuration maps
  /secrets/         - Secret management (encrypted)
  
/terraform/         - Infrastructure as Code

  /azure/           - Azure resources
  /gcp/             - GCP resources

GETTING STARTED:
----------------
Local Development:
1. Install Docker and Docker Compose
2. cd /infrastructure/docker/compose/
3. docker-compose up -d
4. Access services at localhost

Kubernetes Deployment:
1. Install kubectl and helm
2. Configure cluster access
3. kubectl apply -f /kubernetes/
4. Verify: kubectl get pods

Infrastructure Provisioning:
1. Install Terraform
2. cd /infrastructure/terraform/aws/
3. terraform init
4. terraform plan
5. terraform apply
