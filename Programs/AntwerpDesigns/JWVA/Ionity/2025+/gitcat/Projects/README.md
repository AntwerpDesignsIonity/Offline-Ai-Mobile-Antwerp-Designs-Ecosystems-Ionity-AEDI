# Projects Directory

This directory contains projects for the Antwerp Designs Ionity ecosystem.

## Structure

```
Programs/AntwerpDesigns/JWVA/Ionity/2025+/gitcat/Projects/
├── README.md (this file)
└── [Project Name]/
    ├── README.md
    ├── src/
    ├── docs/
    └── config/
```

## Creating a New Project

To create a new project in this directory:

1. Create a new directory with your project name
2. Add a README.md describing your project
3. Organize your code in the `src/` directory
4. Add documentation in the `docs/` directory
5. Store configuration files in the `config/` directory

## Project Naming Convention

- Use descriptive names
- Use hyphens or underscores for spaces
- Keep names concise but meaningful
