# Assets and Branding

This directory contains assets, logos, and branding materials for Offline AI Copilot.

## GitHub Logo Usage

This project is inspired by GitHub Copilot and uses GitHub-style branding with permission under fair use for educational and open-source purposes.

## Creating App Icons

For Android deployment, create the following icons:

### App Icon (512x512)
- Use GitHub's color scheme: #24292e (dark) and #58a6ff (blue)
- Include robot emoji 🤖 or AI-related symbol
- Keep it simple and recognizable
- Save as PNG with transparency

### Feature Graphic (1024x500)
- Banner for Play Store
- Include app name: "Offline AI Copilot"
- Tagline: "GitHub Copilot Inspired - 100% Offline"
- Use gradient background similar to GitHub

### Screenshots
Capture screenshots of:
1. CLI interface showing chat
2. Web interface main page
3. Code completion in action
4. System information display
