SHARED LIBRARIES INDEX
======================

This directory contains shared libraries and utilities used across all platforms in the AEDI platform.

STRUCTURE:
----------
/utils/             - Common utility functions
  /validators/      - Input validation utilities
  /formatters/      - Data formatting functions
  /converters/      - Type conversion utilities
  
/constants/         - Shared constants and enums
/types/             - TypeScript type definitions
/interfaces/        - API interface definitions
/sdk/               - Platform SDKs
  /js-sdk/          - JavaScript/TypeScript SDK
  /python-sdk/      - Python SDK
  /mobile-sdk/      - Mobile (React Native) SDK
  
/ai-sdk/            - AI utilities and helpers
/api-client/        - API client libraries
/hooks/             - React custom hooks (shared)
/components/        - Shared UI components

SDK LIBRARIES:
--------------
JavaScript/TypeScript SDK:
```typescript
import { AEDIClient } from '@aedi/js-sdk';

const client = new AEDIClient({
  apiKey: 'your-api-key',
  baseURL: 'https://api.aedi-platform.com'
});

// User management
await client.users.get(userId);
await client.users.update(userId, data);

// AI features
await client.ai.analyze(text);
await client.ai.predict(data);

// Real-time
client.realtime.connect();
client.realtime.on('message', handler);
```

Python SDK:
```python
from aedi_sdk import AEDIClient

client = AEDIClient(
    api_key='your-api-key',
    base_url='https://api.aedi-platform.com'
)

# User management
user = client.users.get(user_id)
client.users.update(user_id, data)

# AI features
result = client.ai.analyze(text)
prediction = client.ai.predict(data)
```

Mobile SDK (React Native):
```typescript
import { AEDIMobileClient } from '@aedi/mobile-sdk';

const client = new AEDIMobileClient({
  apiKey: 'your-api-key',
  offlineMode: true
});

// Offline-first operations
await client.users.get(userId); // Works offline
await client.sync.start(); // Sync when online
```

GETTING STARTED:
----------------
Installation:
```bash
# JavaScript/TypeScript
npm install @aedi/shared

# Python
pip install aedi-shared

# React Native
npm install @aedi/mobile-shared
```

Usage:
```typescript
// Import utilities
import { validateEmail, formatDate } from '@aedi/shared/utils';
import { API_ENDPOINTS } from '@aedi/shared/constants';
import { User, ApiResponse } from '@aedi/shared/types';

// Use in your code
const isValid = validateEmail(email);
const formatted = formatDate(date, 'YYYY-MM-DD');
```
