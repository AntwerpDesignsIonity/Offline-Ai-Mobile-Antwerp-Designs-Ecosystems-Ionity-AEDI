BACKEND SERVICES INDEX
======================

This directory contains all backend services and APIs for the AEDI platform.

STRUCTURE:
----------
/api/               - RESTful API services
  /v1/              - API version 1
  /v2/              - API version 2 (latest)
  /routes/          - Route definitions
  /controllers/     - Request handlers
  /middleware/      - Express middleware
  
/graphql/           - GraphQL API server
/microservices/     - Microservices architecture
  /auth-service/    - Authentication service
  /user-service/    - User management
  /ai-service/      - AI processing service
  /data-service/    - Data processing
  /notification/    - Notification service
  
/workers/           - Background job processors
/cron/              - Scheduled tasks
/websocket/         - Real-time communication

API ENDPOINTS:
--------------
Authentication:
- POST /api/v2/auth/register
- POST /api/v2/auth/login
- POST /api/v2/auth/refresh
- POST /api/v2/auth/logout

Users:
- GET /api/v2/users
- GET /api/v2/users/:id
- PUT /api/v2/users/:id
- DELETE /api/v2/users/:id

AI Features:
- POST /api/v2/ai/analyze
- POST /api/v2/ai/predict
- POST /api/v2/ai/image-recognition
- POST /api/v2/ai/nlp

GETTING STARTED:
----------------
1. cd /backend/api/
2. npm install
3. Copy .env.example to .env
4. Configure database connection
5. Run migrations: npm run migrate
6. Start server: npm run dev
7. View API docs: http://localhost:3000/api-docs
