AI MODULES INDEX
================

This directory contains all AI/ML modules and integration components for the AEDI platform.

STRUCTURE:
----------
/models/            - Trained AI/ML models
  /nlp/             - Natural Language Processing models
  /vision/          - Computer Vision models
  /recommendation/  - Recommendation systems
  /prediction/      - Predictive models
  
/training/          - Model training scripts
/inference/         - Inference engines
/preprocessing/     - Data preprocessing utilities
/deployment/        - Model deployment configurations
/monitoring/        - Model performance monitoring

GETTING STARTED:
----------------
Training Models:
1. cd /ai-modules/training/
2. pip install -r requirements.txt
3. python train_model.py --config config.yaml

Running Inference:
1. cd /ai-modules/inference/
2. python serve_model.py --model-path ./models/

Integration:
- See /docs/ai-integration.md
